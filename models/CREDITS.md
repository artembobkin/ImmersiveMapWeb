# Third-party assets

`spot.obj`, `spot.mtl`, `spot.png`: "Spot" by Keenan Crane, released into the public domain
(<https://www.cs.cmu.edu/~kmcrane/Projects/ModelRepository/>). Exported to OBJ with Model I/O from the
Swift engine's `Tools/ReadmeFrames/Resources/spot.usdz`, the material's colour set to white so the
texture shows as authored, as the Swift loader draws a textured material.
